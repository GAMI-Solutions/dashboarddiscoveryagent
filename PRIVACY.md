# Privacy Policy

**Dashboard Discovery Agent** collects, stores, and transmits no data.

## What this plugin is

The plugin is a set of Markdown instruction files — a skill definition and a subagent definition. It contains no executable code, makes no network calls, and has no server component. There is nothing in it that can send data anywhere.

## Your dashboard screenshots

Dashboard images you share stay entirely within your Claude conversation and are handled under [Anthropic's privacy policy](https://www.anthropic.com/legal/privacy). The plugin does not copy, forward, log, or retain them, and the author has no access to them.

## Credentials and data access

None required. The plugin requests no API keys, database credentials, or data warehouse connections, and cannot query the data behind your dashboards. It analyzes only the image you paste into the conversation.

## Third parties

No data is shared with the plugin author or any third party.

## Changes

Any change to this policy will be committed to this repository and reflected in the date below.
